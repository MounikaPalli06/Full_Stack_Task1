# Full_Stack_Task1
Full Stack Portfolio Website (HTML, CSS, JavaScript, PHP, MySQL)
This is a modern full-stack portfolio website built using HTML, CSS, JavaScript, PHP, and MySQL. It showcases my projects, skills, and contact information with a clean and responsive user interface.

🚀 Features
🌐 Responsive design (mobile + desktop)
🎨 Modern UI with dark/light theme toggle
🔄 Dynamic GitHub project integration (GitHub API)
📄 Resume download button
📩 Contact form with PHP & MySQL backend
🧾 Form validation using JavaScript
🎥 Multimedia support (video section)
🛠️ Technologies Used
Frontend: HTML5, CSS3, JavaScript
Backend: PHP
Database: MySQL
Version Control: Git & GitHub
📂 Project Structure
portfolio/
│── index.html
│── style.css
│── script.js
│── contact.php
│── db.php
│── assets/
⚙️ Setup Instructions
Clone the repository
Move project to htdocs (XAMPP)
Start Apache & MySQL
Import database using phpMyAdmin
Run:
http://localhost/portfolio

This project is created as part of a learning task to demonstrate:

Frontend development skills

Real-world portfolio design
